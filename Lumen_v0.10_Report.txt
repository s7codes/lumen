LUMEN v0.10.0 - MILESTONE REPORT
Hero Refinement, Header UI Overhaul, Account Page Revival
Branch: feat/design-polish-and-account
Date: 2026-11-11

------------------------------------------------------------------------
SUMMARY
------------------------------------------------------------------------

v0.9.0 pushed the layout too far: an oversized hero pressed against the left
edge, mismatched navbar controls and an /account page with no structure. This
release pulls the hero back to a balanced scale and inset, unifies the navbar
controls into one pill system, rebuilds /account as a bento grid with a
logical Sign Out position, and gives product cards their own entrance.

Result: 96 of 96 Playwright E2E specs pass against the production build.
Zero console errors and zero CSP violations.

------------------------------------------------------------------------
1. HERO TYPOGRAPHY
------------------------------------------------------------------------

Files: src/styles/tokens.css, src/styles/home.css

- New token --text-hero: clamp(3rem, 1.2rem + 5.2vw, 7rem). The headline now
  tops out at 7rem instead of 9rem. Measured: 94px at 1440 wide, 112px cap
  from about 1800 wide (126px at 2560, where the root type is 18px).
- New token --tracking-hero: -0.04em (was -0.052em). Slightly looser
  tracking suits the smaller size.
- Headline measure widened from 11ch to 12ch so the line breaks stay calm at
  the reduced size.
- --text-display (9rem) is kept as a token but no longer drives the hero.

Horizontal position
- --hero-inset: clamp(24px, 9vw, 220px), was clamp(20px, 5.5vw, 120px).
  At 1280 wide the copy now sits 115px off the edge (was 70px); at 1440,
  130px; from 2445 wide, 220px.

Vertical position
- Bottom padding reduced to clamp(32px, 3.5vw, 96px), so the copy block sits
  lower in the frame. The top margin floor is raised to
  clamp(32px, 16vh - 40px, 160px) so short viewports keep air above the
  index label.
- Measured at 1440 x 900: 244px above the copy, 50px below it.

3. ACCOUNT PAGE
------------------------------------------------------------------------

Files: src/pages/AccountPage.jsx, src/styles/account.css,
       src/styles/pages.css, src/styles/tokens.css

Atmosphere
- New token --glow-oak:
  radial-gradient(circle at top right, rgba(232,146,58,0.05), transparent 40%)
- New utility .page-atmosphere in pages.css paints it as a fixed layer under
  the page content and over the basalt canvas. It does not catch pointer
  events. It is applied to /account only.

Layout
- The page is one bento grid (.bento: 16px radius, 1px
  rgba(255,255,255,0.06) edge, 16px backdrop blur).
- 01 / Profile: a full-width tile with the user's name as a headline, email
  in monospace, and a ruled facts row: Storage, Sync, Projects count, Quotes
  count. These facts moved here from the page header meta line.
- 02 / Projects (Saved Spatial Projects) and 03 / Quotes (Order History) sit
  side by side below it at 1.45 : 1. They stack under 960px.
- Saved project cards are now inset tiles (12px radius, hairline edge) inside
  the projects panel, with a brighter edge on hover.
- Order rows are separated by hairline rules instead of loose spacing.
- The three tiles use the cinematic reveal (1.05 to 1.0 scale, 8px blur to
  none) with a 100ms stagger.

Sign Out
- Moved from a loose bar under the header into the profile tile's top-right
  corner, aligned to the tile's padding edge. On phones it drops below the
  name and email.

4. PRODUCT CARD ENTRANCE
------------------------------------------------------------------------

Files: src/components/ProductCard.jsx, src/hooks/useScrollReveal.js,
       src/styles/animations.css, src/styles/tokens.css,
       src/pages/CatalogPage.jsx, src/pages/HomePage.jsx

- Every ProductCard is now its own reveal target (.reveal-card). When it
  enters the viewport it grows from scale 0.95 to 1.0, fades from 0 to 1 and
  clears a 4px blur over 1000ms on cubic-bezier(0.16, 1, 0.3, 1).
- The entrance lives in the component, so it works anywhere the card is used.
  The grid cells on the home page and the catalog no longer carry their own
  1.05 cinematic reveal, which would have cancelled the scale-up.
- It animates the individual CSS scale property, not transform, so the
  spring-driven 3D tilt (inline transform) composes with it.
- It runs as a keyframe animation, not a transition, so the card's own
  border and shadow hover transitions are untouched.
- Stagger: useScrollReveal now finds the nearest .reveal-stagger ancestor
  instead of only the direct parent, so cards inside grid cells still land
  at 0, 100 and 200ms.
- Settling: the hook now also listens for animationend, so compositor hints
  (will-change) drop as soon as the entrance ends.
- New tokens: --reveal-card-scale 0.95, --duration-card 1000ms.
- prefers-reduced-motion: cards render at rest with no animation.

v0.10.1 - CART NAMING PATCH
------------------------------------------------------------------------

v0.10.0 renamed only the navbar trigger and drawer title. v0.10.1 finishes
the copy pass: every visible label, button, toast and screen reader
announcement that said bag now says cart.

Renamed (20 strings, 10 files)
- Product card and spec sheet: "Add to Bag" to "Add to Cart", "In bag n" to
  "In cart n", "Not in bag" to "Not in cart".
- Drawer: "Clear bag" to "Clear cart", "Your bag is empty." to "Your cart is
  empty.", list label "Bag contents" to "Cart contents".
- Toasts and live announcements: "added to cart.", "removed ... from the
  cart.", "Cart cleared: n items removed."
- Planners: "Sync Wall to Cart", "Sync Room to Cart", and the status lines
  "Synced n modules as n cart lines."
- Page copy: the Home Wall Studio card, Room Planner and Wall Studio ledes,
  and the empty checkout notice.

Kept on purpose
- Internal names stay bag: the useBag hook, BagProvider and BagDrawer
  components, CSS classes, test ids and the lumen_bag_v1 storage key.
  Renaming the storage key would drop every cart already saved in a
  visitor's browser, and the other names are never shown to users.

Tests
- Role names, toast text and status line assertions updated to the cart
  copy in auth-and-toast, bag-drawer, product-detail-and-checkout,
  room-planner-3d, surface-lab, ux-animations and wall-studio specs.

Release
- package.json and package-lock.json: 0.10.0 to 0.10.1; README updated;
  tagged v0.10.1. The v0.10.0 tag is left where it was.
